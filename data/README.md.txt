# Dataset

## Credit Card Fraud Detection Dataset

This project uses a real-world credit card transaction dataset for fraud detection.

### Dataset Information

- Total records: 1,296,675
- Total columns: 23
- Target variable: `is_fraud`
- `0` = Legitimate transaction
- `1` = Fraudulent transaction

### Class Distribution

- Legitimate transactions: 1,289,169
- Fraudulent transactions: 7,506

Fraudulent transactions represent approximately 0.58% of the complete dataset.

### Raw Dataset

The original CSV dataset is not included in this repository because of its large size.

The dataset was loaded in Google Colab as:

`train.csv`

The complete data loading, preprocessing, feature engineering, and modeling workflow is available in the notebook.
